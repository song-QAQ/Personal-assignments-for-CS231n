# Personal-assignments-for-CS231n

## 背景
如你所见，我前一段开始看CS231n课程，真的很不错。
这个仓库用来存储课程提供的作业，我可能会翻译，完成，写点自己的东西什么的。
至于ai工具会不会在完成中起到作用，我会说是肯定的，这能为我缩短许多学习的时间（虽然很损伤我的Coding能力:-P）我没有一个学期的时间来慢慢写。不过我能够向你保证，ai的产出我会学习阅读后才放出来，同时大部分是我来写代码ai改（虽然我不知道我的代码水平有没有ai高）。如果你很讨厌ai，并且厌恶ai的产出的话，建议避开这个仓库。
